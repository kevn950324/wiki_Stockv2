# 技術_大模型推理經濟學

## 定義

大模型推理經濟學研究「模型能力如何轉成可持續的每任務收入與毛利」。單看每百萬 token 報價會漏掉模型為完成同一任務所需的輸出長度、重試率、延遲、KV-cache、active parameters、硬體利用率與通路分潤；更接近商業真相的單位是 **cost per completed task** 與 **gross profit per workload**。

2026 年中國模型價格顯著低於美國 frontier model，但 [[報告_Jefferies_中國AI_Token支出與模型效率_20260810]] 顯示中國模型在 OpenRouter 的 token 使用量快速上升。這使投資問題從「誰最聰明」轉成「誰能同時維持 Pareto frontier：足夠能力、低任務成本、高吞吐與可變現的付費用量」。相關硬體層見 [[技術_AI推論與ASIC平台]]，訓練後強化層見 [[技術_RL訓練系統_GRPO]]。

## 技術原理

| 模組 | 功能 | 觀察重點 |
|---|---|---|
| 模型能力 | 決定任務成功率、可處理複雜度與定價上限 | benchmark 應搭配真實 coding／agent 成功率 |
| MoE 路由 | 每 token 只啟用部分 experts | 看 active parameters 絕對量，不只 activation ratio |
| Attention／KV-cache | 保存上下文狀態並決定長序列記憶體流量 | MLA、GQA、sparse attention、KV sharing 的實際記憶體節省 |
| Prefill／decode 分離 | 把吞吐導向的 prefill 與低延遲 decode 分池 | GPU 利用率、排程、網路與 tail latency |
| Speculative decoding | 以草稿 token 降低逐 token decode 延遲 | acceptance length、品質與額外計算成本 |
| 量化與 kernel | 以較低精度和融合算子提升 tokens/s | 精度損失、硬體相容與本土晶片移植成本 |
| API／MaaS 計費 | 將模型服務按 token、媒體或訂閱收費 | realized price、折扣、通路分潤、客戶留存 |
| ARR 年化 | 把近期收入 run-rate 年化 | 不等於歷史收入；需看 cohort、季節性與 gross／net 口徑 |

與一般軟體 SaaS 不同，LLM 每次使用都會產生推理成本；用量增加可以推升收入，也會同步拉升 COGS。只有當價格、每任務 token、硬體利用率與模型效率的改善快於服務成本時，token 成長才會轉成毛利槓桿。

## 關鍵參數 / 判斷指標

| 指標 | 意義 | 投資觀察 |
|---|---|---|
| Intelligence／task benchmark | 能力與定價上限 | 單次排名易變，連續迭代與付費留存更重要 |
| 每百萬 input／output token 價格 | 名目報價 | output 通常較貴，長推理會侵蝕「低價」優勢 |
| Cost per completed task | 同一結果的總成本 | 最適合比較不同模型；需納入重試與失敗 |
| Active parameters／token | MoE 每 token 的計算代理變數 | 絕對量小通常有利 serving memory 與互連 |
| Tokens/s、TTFT、interactivity | 吞吐與使用體驗 | 高 throughput 支撐 API 毛利；低延遲支撐 agent／coding |
| MFU／GPU utilization | 算力轉有效 FLOPs 的效率 | 利用率提升可降低單位 COGS，亦拉動軟體優化價值 |
| Token 使用量／份額 | 真實採用與工作負載 | 需分辨免費、第三方託管與公司可認列收入 |
| API gross margin | 收入扣推理成本後的品質 | 比 ARR 更能驗證商業模式是否成立 |
| ARR→revenue conversion | 年化動能轉報表收入 | 用 cohort、續約與 recognized revenue 核對 |
| Compute service cost／revenue | 算力費用強度 | 比低 capex 更能判斷租賃型模型公司的經濟性 |

## 產業動能

- **Token 使用量仍在擴張**：[[報告_Jefferies_中國AI_Token支出與模型效率_20260810]]（2026-08-10）記錄 OpenRouter 當週 token 約 69tn、週增 21.5%，中國模型約 34.2tn，高於美國模型約 9.2tn；平台樣本不代表全市場，但可作即時採用指標。
- **價格下降促進用量，但能力溢價仍存在**：[[報告_Daiwa_中國基礎模型產業啟動覆蓋_20260811]]（2026-08-11）估中國 top-model median blended price 約 US$0.8／m tokens，低於美國約 US$6.6；同一報告又指出 [[2513.HK(z.ai)]] 在提價後仍增長，顯示強 coding／agent 能力可保留定價權。
- **低成本不只來自 MoE**：[[報告_JPM_GLM5.3與DeepSeek重新定價_20260816]]（2026-08-16）把 DeepSeek 的優勢拆成 MoE、attention／KV-cache、量化與 serving engineering，說明架構、kernel 和運維須一起看。
- **算力瓶頸從訓練延伸到推理**：[[報告_Daiwa_中國基礎模型產業啟動覆蓋_20260811]] 指 [[2513.HK(z.ai)]] 2026-07 的主要增量算力偏向推理；若付費需求高於可用算力，ARR 上行仍可能被 capacity cap 限制。
- **企業 monetisation 早於消費端已成長期基準**：[[報告_Nomura_中國AI全球生成式AI發展映射_20230917]]（2023-09-17）較早即判斷中國 GenAI 先由企業／政府付費；2026 年 [[0100.HK(minimax)]]、[[2513.HK(z.ai)]] 的 API／MaaS 資料驗證了這條路徑，但盈利尚未確立。

> 模型價格、參數與第三方 token 流量有報告／平台資料支撐，信心中；ARR、私人估值、2029–30 損平及特定算力容量多為公司口徑或券商 estimate，信心中低，須以財報與部署資料驗證。

## 技術瓶頸 / 風險

- **每 token 便宜但每任務未必便宜**：推理鏈變長、CoT 輸出增加或重試率偏高，都可能反轉表面價格優勢。
- **benchmark 易被 gaming 且更新快**：公開測試不能完整代表 reliability、latency、工具調用成功率與企業安全。
- **供給與軟體堆疊綁定**：先進 GPU、本土加速器、HBM、互連與 kernel 任一不足，都會降低實際 tokens/s 與毛利。
- **低切換成本壓抑定價**：標準 API 與聚合平台讓開發者容易換模型；只有 workflow、資料、記憶與 agent 深度整合才可能提高黏著。
- **ARR 可比性有限**：gross／net、partner commission、第三方託管與年化時點不同，直接套用 EV/ARR 容易高估價值。
- **效率提升的反彈效應未必落到單一公司**：更低成本可推升總 token，但份額可能在模型供應商、雲端平台、晶片與應用層間重新分配。

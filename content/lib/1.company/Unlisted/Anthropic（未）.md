# Anthropic（未）

## 基本資料

| 項目 | 內容 |
|------|------|
| 全名 | Anthropic PBC |
| 成立 | 2021 年初（Dario Amodei 離開 OpenAI 創立） |

| IPO 狀態 | 2026-06-01 機密申報（Confidential S-1 filing） |

Anthropic 是美國 AI 安全公司，旗下 **Claude** 模型系列為主力產品。2026 年上半年 **Claude Code** 爆發性成長（佔 GitHub 總 commit 數達 7.3%），驅動 ARR 從 2025 年底 $9B 快速攀升至 2026 年 7 月逾 **$60B**，是全球 B2B AI 服務最高成長速度之一。

### 2026-10-26 S-1 公開申報（Nasdaq，代號 ANT）

- 季營收（百萬美元）：1Q25 376、2Q25 787、3Q25 1,382、4Q25 2,040、1Q26 4,731、2Q26 11,555；2Q26 年增 1,368%，首次 GAAP 營業利益轉正 US$974mn；S-1 未列 3Q，只寫為 4Q24 的 86 倍，大叔換算約 US$16.8–17.1bn。1H26 營收 US$16.286bn（年增約 13 倍），其中用量計費約 80%（US$13.1bn）、訂閱約 20%（US$3.2bn）。
- 1H26 帳面淨虧損 US$80.7bn，其中約 US$72.4bn 為可轉債等公允價值變動、約 US$9.4bn 來自票據購買協議（非現金）；營業虧損約 US$690mn；現金與短期投資約 US$131.7bn（現金 US$112.4bn＋短投 US$19.3bn），帳上負債 US$6.2bn、未動用循環信貸 US$15bn。1H26 支出 US$8.95bn（年增 283%），占營收比由約 200% 降至 55%，研發占比由 2025 年 138% 降至 60%（永豐整理）。
- 營收以總額認列：經 AWS、GCP、Azure 市集銷售全額記營收，市集占比 32%（2024）→ 47%（2025）→ 48%（1H26）。run-rate 定義為過去 28 天用量費 × 13＋月訂閱費 × 12，含違規客戶且有季節性。違反使用政策（蒸餾）客戶約占前九個月營收 5%–7%（約 US$1.7–2.3bn），8–9 月加強執法。
- 需求：NRR 約 900%（不含 Pro／Max）；年付逾 US$100k／1mn／10mn 客戶 11,900+／1,900+／約 250 家；無單一客戶逾 10%、前五大約 25%，3Q 有 79% 營收來自前五大以外（1Q 為 64%）；同時用 Claude Code 的企業花費約為其他客戶 20 倍。cRPO 約 US$8.1bn，不到年化營收（約 US$46bn）二成。
- 算力承諾（大叔整理）：Broadcom TPU 租約約 US$161bn、SpaceXAI（NVIDIA GPU）最多約 US$121bn（12 月起每月約 US$3.1bn）、Google 至少 US$115bn（另 2028–31 年 US$125–150bn TPU 容量）、Amazon 至少 US$110bn、Microsoft 至少 US$45bn、Nscale 約 US$45bn、Lambda 約 US$41bn、AMD 逾 US$20bn，合計約 US$780–810bn；Broadcom 租約、信用協議與可轉債有交叉違約條款。永豐稱資產負債表外算力承諾 US$637bn，約三分之二不可取消。
- 稀釋：可轉債額度 US$77bn（Google 20bn、Amazon 15bn、Broadcom 42bn，以 VWAP 換股），Google 可再以 IPO 價買 US$10bn；公益基金持完全稀釋後 5%，股價每漲 50% 最多再加 2%。市場消息指可能 11-16 當週上市（中信、國泰晨報轉述，非 S-1 內容）。
- 來源：[[memo_大叔美股筆記_AnthropicS1七大重點_20261027]]（大叔美股筆記，2026-10-27）、[[隨手記_2026-10-27_中央社：Anthropic增長勢頭猛年化]]（永豐投顧評析），信心中高。

### 2026-10-31 FOMOSoc：S-1 四大重點（毛利口徑、現金與承諾、獲利窗口期、收入品質）

- 毛利口徑：1H26 營收 US$16.28bn、銷貨成本 US$2.38bn，毛利率 85.4%；但 1H26 算力與基礎設施支出 US$8.95bn 中只有約 US$2.4bn 進銷貨成本，其餘約 US$6.5bn 多數列研發（模型訓練與內部測試），小部分列銷售與行銷（免費版 Claude 推論）。研發中訓練成本約 US$9.74bn。功能別拆解每 US$100 營收：扣推論與伺服器成本剩 85.4 → 扣銷售與行銷（23.4，約 US$3.8bn，含雲端市集通路費）剩 62 → 扣研發與管理後 −4.3。營收少約 4%，1H 虧損即成倍擴大。
- 通路：近一半營收經 Amazon、Google、Microsoft 雲端市集銷售（2023 年約 11%）；三家同時是算力供應商（Amazon 至少約 US$110bn、Google 至少約 US$114.5bn、Microsoft 至少約 US$45bn 長期承諾）、投資人與競爭者，作者稱為準 Keiretsu 結構。
- 現金與負債：2026-06 底現金與短投約 US$131.7bn；累計融資約 US$141bn，其中 1H26 約 US$110bn（5 月 Series H 約 US$65bn）。帳上約 US$108.6bn 負債來自 Amazon 可轉債（本金約 US$6.2bn）採公允價值選擇權標價，IPO 轉股後消失；經濟淨現金約 US$125.5bn。1H26 利息收入 US$1.11bn，2Q26 US$762mn，相當於當季營業利益 78%。1H26 營運現金流約 US$3.9bn。另有約 US$15bn 未動用循環信貸、Google／Amazon／Broadcom 條件性票據融資最高約 US$77bn；循環信貸自 2026-12-31 起要求每季末流動性至少 US$5bn。SpaceXAI 產能約 2026-12 全部到位後每月支出約 US$3.1bn。
- 獲利窗口期：2Q26 營業利益約 US$974mn（利潤率 8.4%，前五季皆虧），1H26 營業虧損約 US$693mn；算力支出占營收由 1Q25 251% 降至 2Q26 48%。10 月中投資人會議透露 3Q26 營收約 US$16.8bn（季增約 45%，2Q 季增約 144%），調整後獲利、現金流為正，每 US$1 算力約賺回 US$1.7 營收。2Q26 調整後利潤率約 19% vs GAAP 8.4%，差距主要為 SBC（2Q 約 US$1.3bn、占營收約 11%；1H 約 US$2.2bn）；剩餘 RSU 費用估約 US$26.6bn，IPO 時立即認列約 US$2.9bn，其餘約 US$23.7bn 約 2.1 年攤銷。
- 收入品質：年付逾 US$100k 企業逾 11,900 家，含過半 Fortune 500 與全部 Fortune 10；Fortune 500 客戶平均 Anthropic 支出不到其總支出 0.1%，前十大客戶亦不到 1%。僅用 Claude 企業版者每月平均不到 US$75，占 5% 的 Claude Code 重度用戶花費為其 20 倍。Claude Opus 5.5 客戶每任務成本較前代降約 40%。約八成收入為用量計費；前九個月 5%–7% 收入來自違規（蒸餾）客戶；NRR 約 900% 不含 Pro／Max。Meta、Microsoft 據報節制內部使用。
- 內部生產力（公司自報）：2026-09 內部程式碼逾 90% 由 Claude 撰寫；每位工程師每日貢獻程式碼為 2024 年平均 45 倍以上；員工數 2024 年底至 2026-09 成長逾 5 倍，人均 TTM 營收由約 US$1.4mn 升至逾 US$6.6mn；內部 Claude 使用的列表價值 1–9 月成長逾 250 倍，4 月起超過每月人事成本（不含股權獎勵）。
- IPO 估值：市場討論區間約 US$1.5–2tn（非 S-1 內容）。

## 業務結構

- **API（usage-based）**：75-85% of total ARR；B2B enterprise 為主；毛利率顯著高於訂閱
- **訂閱（Consumer/Team/Enterprise）**：約 15% of total ARR
  - Consumer: Free / Pro $20/月 / Max 5x $100/月 / Max 20x $200/月
  - Team: $20 或 $100/月（年付，5-150 席次）
  - Enterprise: 150 席次以上改為 $20/月訂閱費 + API 費率

**對比 OpenAI（2026 Q1-Q2）**：OpenAI 訂閱佔 65%+、Consumer 佔 40%，Anthropic 正好相反；Anthropic API 毛利率遠優於 OpenAI 訂閱模式。

## IPO 背景

- **機密申報**：2026-06-01（S-1 Confidential Filing）
- **IPO 理由**：①進入股票/債務市場（未來必需）②公開財報增強企業信心（百億級合同）③員工流動性
- **競爭環境**：Google 2026 年 6 月籌資 $84.75B；Meta 計劃籌資數十億；超大規模算力建設需求持續
- **SemiAnalysis 估值**：以「第一個 $6T 公司」作為基線可能性（如持續執行）

> [!note] OpenAI vs Anthropic 財務差異
> OpenAI 2026 Q2 末估計：B2B 佔 40%、Consumer 約 40%、高昂的訂閱模式使毛利率低於 API；据報 OpenAI IPO 推遲至 2027。Anthropic 則 API 主導（75-85%），B2B 定位清晰，毛利結構更優。

## Meta-Anthropic 算力夥伴關係（2026 年潛在協議）

SemiAnalysis（2026-07-02）獨家報導：**Meta 正處於與 Anthropic 洽談私有 Claude 實例的最終階段**，模式類似 AWS Bedrock。可能包含：

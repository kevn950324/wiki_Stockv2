# Anthropic（未）

## 基本資料

| 項目 | 內容 |
|------|------|
| 全名 | Anthropic PBC |
| 成立 | 2021 年初（Dario Amodei 離開 OpenAI 創立） |
| 總部 | 美國舊金山 |
| 創辦人 | Dario Amodei（CEO）、Daniela Amodei（President） |
| 主要產品 | Claude 系列 AI 模型、Claude Code、Claude API |
| IPO 狀態 | 2026-06-01 機密申報（Confidential S-1 filing） |

Anthropic 是美國 AI 安全公司，旗下 **Claude** 模型系列為主力產品。2026 年上半年 **Claude Code** 爆發性成長（佔 GitHub 總 commit 數達 7.3%），驅動 ARR 從 2025 年底 $9B 快速攀升至 2026 年 7 月逾 **$60B**，是全球 B2B AI 服務最高成長速度之一。

## 業務結構

- **API（usage-based）**：75-85% of total ARR；B2B enterprise 為主；毛利率顯著高於訂閱
- **訂閱（Consumer/Team/Enterprise）**：約 15% of total ARR
  - Consumer: Free / Pro $20/月 / Max 5x $100/月 / Max 20x $200/月
  - Team: $20 或 $100/月（年付，5-150 席次）
  - Enterprise: 150 席次以上改為 $20/月訂閱費 + API 費率

**對比 OpenAI（2026 Q1-Q2）**：OpenAI 訂閱佔 65%+、Consumer 佔 40%，Anthropic 正好相反；Anthropic API 毛利率遠優於 OpenAI 訂閱模式。

## IPO 背景

- **機密申報**：2026-06-01（S-1 Confidential Filing）
- **IPO 理由**：①進入股票/債務市場（未來必需）②公開財報增強企業信心（百億級合同）③員工流動性
- **競爭環境**：Google 2026 年 6 月籌資 $84.75B；Meta 計劃籌資數十億；超大規模算力建設需求持續
- **SemiAnalysis 估值**：以「第一個 $6T 公司」作為基線可能性（如持續執行）

> [!note] OpenAI vs Anthropic 財務差異
> OpenAI 2026 Q2 末估計：B2B 佔 40%、Consumer 約 40%、高昂的訂閱模式使毛利率低於 API；据報 OpenAI IPO 推遲至 2027。Anthropic 則 API 主導（75-85%），B2B 定位清晰，毛利結構更優。

## 風險 / 注意事項

- **計算供需缺口**：1Q26 期間用戶感受到算力限制（rate limit、downtime）；預計持續至融資完成並擴展算力
- **資本競爭加劇**：Google、Meta、OpenAI 等均在搶佔同一算力資源
- **模型領先地位能否持續**：開源（Meta LLaMA 等）及中系模型仍在追趕

## Meta-Anthropic 算力夥伴關係（2026 年潛在協議）

SemiAnalysis（2026-07-02）獨家報導：**Meta 正處於與 Anthropic 洽談私有 Claude 實例的最終階段**，模式類似 AWS Bedrock。可能包含：
1. Meta 內部員工使用（安全隔離的私有實例）
2. Meta 對外銷售 Claude API（類似 Bedrock TaaS）
3. Meta 整合 Claude 進廣告/行銷 SaaS 應用

> [!warning] 資料衝突風險
> Anthropic Claude Code 平台目前 Meta 是約 35% 客戶（SemiAnalysis Tokenomics 估計）；但「私有算力換托管」計畫若實現，意義遠大於普通企業訂閱關係。此資訊目前僅 SemiAnalysis 一家，claim 類型 exclusive/rumor，信心低。

SpaceX 方面，SpaceX 已簽署向 Anthropic 提供 $26B/yr GPU 算力的合約（SemiAnalysis 2026-07-09 提及），SpaceX compute deal 結構：3 年但雙方 90 天可取消。

# 8155_博智（櫃）

## 基本資料
博智電子（ACCL）為台灣上櫃 PCB 廠，提供伺服器、工業電腦與網通用多層板。公司在 2026 年 9 月座談會表示，Server 約占應用營收 80%、IPC 約 20%、網通約 1%（為公司約數，合計略高於 100%）；14 層以上板約占 PCB 組合 80%。AI／ASIC 伺服器與高階 IPC 推動層數、厚度及產品組合升級，越南新廠若如期爬坡，將增加供給空間。掛牌資訊參照[博智公司簡介](https://www.accl.com.tw/tw/modules/news/article.php?storyid=1)與[櫃買中心上櫃公告](https://www.tpex.org.tw/storage/eb_data/10112/10100301961.htm)；營運觀察來源為 [[活動_博智8155_華南投顧_20260924]]（華南投顧，2026-09-24）。

## 核心技術／競爭優勢
- 多層板能力：公司稱 14 層以上產品約占組合 80%，現有量產出貨最高約 50 層；設備技術能力最高約 72 層、板厚 8 mm。設備能力不等於可穩定量產或客戶認證規格。
- AI 伺服器板卡覆蓋：座談會稱已供應伺服器／Rack 內多種板件；GPU 加速卡最高階 HDI 板尚未大量出貨，部分新平台 CPU 板處於打樣與小量產。
- 高階 IPC 與產品組合：高階 IPC 可使用 40 多層板；公司以解決高階板製程瓶頸、提高層數與 ASP 作為台灣廠方向，若面積不增仍有組合改善空間。
- 越南產能布局：一期設備設定以 18 層以上板為主，客戶需求下約 20% 規劃配置更高階、更厚及更大尺寸板；目前仍是建置與爬坡計畫。

## 2026-11-12 3Q26 法說

- 3Q26（fact／高）：營收 16.81 億元（季增 5.5%、年增 38.6%）；毛利率 26.85%（季增 3.03ppt，高階產品比重提高、材料成本轉嫁順利）；營益率 18.31%；歸屬母公司淨利 2.78 億元，EPS 4.49 元（中信）／4.41 元（富邦，以股本 6.3 億元計）。1–3Q26 EPS 11.15 元（中信）／10.81 元（富邦）。
- 產品組合（1–3Q26）：Server 82%、IC Tester 9%、IPC 7%、Networking 1%、其他 1%；層別 2–12L 23%、14–20L 50%、22–48+L 27%。目前 ASIC Server CPU 板成長最明顯；NVIDIA Vera CPU 板釋出給 ODM，公司配合生產；未承接 AWS 加速卡（需六階 HDI、產線不足）。
- 技術：客戶由 N+N 轉向 N+M 不對稱設計，以 Sintering 堆疊解決高縱橫比；未來兩到三年 Server 層數 >30L、材料升級 M8–M10。
- 越南 ACM（與 Meiko 合資，河內）：9 月設備進機，1Q27 取得營運執照、2Q27 量產；規劃除 IC 測試板外與台灣同能力；Meiko 為 SpaceX 供應商，越南廠有機會承接衛星板與 AI 衛星需求。台灣廠稼動率 90% 以上。
- CCL 吃緊：三家台灣 CCL 供應商 E 布交期 8–20 週；客戶願下長單並建立替代料。訂單能見度 Server 6–8 個月、IPC 6–12 個月、IC Tester 3–6 個月。
- 展望：2027 年 AI Server 持續增加、IPC B/B 大於 1（主要客戶研華）、IC Tester 機種與客戶增加；中信正面看待，富邦正向看待。

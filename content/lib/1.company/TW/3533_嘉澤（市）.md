# 3533_嘉澤（市）

## 基本資料

嘉澤端子工業（3533 TT）是台灣 AI 伺服器連接器與插槽（Socket）龍頭供應商，核心產品為 CPU 插槽、GPU 電源連接器與高速訊號連接器，廣泛應用於 Nvidia GB/VR 及 AMD Helios AI 機櫃。

成長驅動：(1) AMD Helios 機櫃 2026Q4 量產，嘉澤為 AMD CPU/GPU 插槽主要供應商；(2) VR NVL72 Vera CPU 需求驅動代理型 AI 對 CPU 插槽需求大增；(3) AI 機櫃每代電源連接器規格升級。

2026-05 月營收 MoM -10%、YoY +9%，4-5 月累計達成凱基 2Q26 預估的 63%。

資料來源：[[凱基-電子硬體產業-20260616]]（2026-06-16，凱基投顧）

## 核心技術／競爭優勢

- **AI 伺服器插槽壟斷地位**：Nvidia GB/VR 及 AMD Helios 平台插槽認證，無可替代
- **AMD Helios 核心供應商**：緯穎 Helios 機櫃供應鏈（健策均熱片 + 嘉澤插槽 + 緯穎機櫃）
- **Vera CPU 受惠**：代理型 AI 對 CPU 需求顯著提升，Vera CPU 插槽 ASP 更高
- **訊號連接器技術**：支援高速訊號傳輸的精密連接器，進入門檻高

### 2026-08-18～19 Nomura Asia Tech Tour

- **伺服器平台**：新平台放量是毛利率改善關鍵（新定價機制對應原物料漲價）；公司預期 AMD Venice 至 2026 年底滲透較慢、Intel Oak Stream 1Q27 才開始放量。兩平台起量後，新 socket 與 PCIe 6.0 線材／連接器份額提升可加速成長。
- **短期量能**：雖有伺服器 CPU 平台客戶 2026 年預測更積極，但因記憶體、PCB 等零組件短缺，2H26 伺服器主機板生產量略降。
- **CSP 與新產品**：與一家 CSP 洽談其 ARM CPU 用 socket，量產時程 2H27E；該 CSP 的 AI xPU 仍用板對板連接器，嘉澤不在供應名單。SOCAMM 連接器與 QD 2H26 營收貢獻皆優於年初管理層預期。
- **可拆式 CPO／NPO socket**：有 2 家潛在客戶，其中 1 家由子公司 Lintes（6715 TT）支援；直接客戶潛在量產 **2H27E**，可能需提高中國與越南擴產資本支出，近期增資與可轉債籌資可支應。NPO socket 外型小於 CPU socket，但因複雜度與支援 224G SerDes，ASP 可能高於最新一代 CPU socket **20–30%**。
- 評等：Nomura Buy、TP NT$2,720（24x 2027F EPS NT$113.3），報告時約 14x 2027F EPS。
- 來源：[[Nomura tech tour]]（Nomura，2026-08-20；公司說法轉述與券商 estimate，信心中）。

> [!warning] 平台與 NPO socket 時程口徑
> - Intel Oak Stream：Nomura 轉述 1Q27 開始放量；富邦（2026-09-23）估 2Q27 初量產。
> - NPO socket：Nomura 轉述直接客戶 2H27E 潛在量產；UBS（2026-09-15）估 3Q27、富邦估 2H27 出貨。三者相容但精度不同，均非客戶確認時程。
> - ASP：Nomura 的 NPO socket 較 CPU socket 高 20–30%，與富邦估 CPU socket 隨 pin 數／PCIe 6.0 升級 ASP 提高逾 15% 為不同產品比較，不相加。

# SPCX.US(spacex)

## 基本資料

SpaceX（Space Exploration Technologies Corp.）是全球最大商業航太公司，同時擁有 Starlink 全球衛星寬頻網路與 xAI（2026-02 收購）AI 算力業務。2026-06 IPO 於 Nasdaq（代號 SPCX），主承銷商 Goldman Sachs、Morgan Stanley、JPMorgan 等。

主要資料來源：[[說明書_SpaceX_IPO路演簡報_20260606]]

## 三大業務平台

### 1. Space（太空發射）

| 指標 | 數據 |
|------|------|
| 總發射次數 | ~650 |
| 2025 年使用回收推進器比例 | >95% |
| 2023年起全球入軌總質量佔比 | **80%+** |
| 安全運送太空人（自2020）| 78 人 |
| Dragon 太空站造訪次數 | 50+ |

火箭型號：
- **Falcon 9**：LEO 23 噸，~620 次飛行，99% 成功率
- **Falcon Heavy**：LEO 64 噸，11 次飛行，100% 成功率
- **Starship V3**：LEO 100 噸，12 次測試飛行（含 V3 首飛 May-26）；目標 H2 2026 開始軌道有效載荷交付

### 2. Connectivity（Starlink）

| 指標 | 數據 |
|------|------|
| 衛星總數 | 9,600+ |
| 全球可機動衛星市佔 | ~75% |
| Starlink 用戶 | ~10.3M（Feb-26 突破 1000 萬）|
| 覆蓋國家 | 164 |

衛星升級路線：

| 版本 | 每顆頻寬 | 每次 Starship 發射顆數 | 每次發射頻寬 |
|------|---------|---------------------|------------|
| V2（現在）| 96 Gbps | 60 / Falcon 9 27 | 5,760 Gbps |
| V3（H2 2026）| 1,024 Gbps | — / Starship | 61,000 Gbps |

V3 比 V2 每次發射頻寬 **>20x**。

### 3. AI（xAI + Colossus + Grok）

SpaceX 2026-02 收購 xAI，整合後形成太空 + AI 算力的獨特平台。

| 指標 | 數據 |
|------|------|
| 算力集群名義功率 | ~1.0 GW（Colossus）|
| Grok MAU（X + Grok）| ~550M |
| X 每日貼文 | ~350M |
| Grok 主要版本 | 4 個（至 2026 年）|

**Colossus II 下一階段（announced）**：
- 400MW+ 計算功率
- 220,000+ GB300（NVIDIA Blackwell Ultra）

**2026 重大里程碑**：
- Feb-26：收購 xAI；Starlink 突破 10M 用戶
- Mar-26：Terafab（Tesla + Intel 合作世界最大晶片製造廠）
- Apr-26：X Ads Manager 上線；Grok 4.3 發布；Cursor 夥伴關係
- May-26：Cloud Services Agreements；EchoStar 頻譜執照（FCC）

**AI 衛星算力（2028 路線圖）**：
- 2028 年起由 Starship 部署 AI 衛星
- 100KW 算力 / 噸

## Terafab

SpaceX 與 Tesla、Intel 戰略合作打造全球最大晶片製造廠（Terafab）。
- 宣布時間：2026-03
- 目的：垂直整合 AI 算力所需晶片製造能力

## 競爭優勢摘要

1. 全球唯一廉價可重複使用大型火箭艦隊（Falcon 9 + Starship）
2. Starlink 入軌頻寬全球 #1，V3 衛星 >20x V2
3. xAI + Grok 模型的 real-time 信息優勢（X 平台）
4. 極度垂直整合：自製火箭引擎、自製衛星、自製用戶終端
5. 唯一能夠建造軌道 AI 算力的公司（2028E）

## 目標市場規模

- 現有可服務市場：**$6 兆（$6T）**（Space + Connectivity + AI）
- AI 時代帶來更大機會（詳見 IPO 路演圖 Slide 14）

# 2513.HK(z.ai)

## 基本資料

Z.AI（智譜）是中國基礎模型與 MaaS 公司，收入分為 Open Platform／API、企業 agent、企業基礎模型私有部署及少量技術服務。2025 年收入約 RMB724m：企業基礎模型 RMB366m（50%）、企業 agent RMB166m（23%）、Open Platform／API RMB190m（26%）。其成長策略正由人力密集的 on-premise 專案轉向可擴張的 coding／agent API；Daiwa 指 cloud ARR 由 2025 年初約 US$4m 升至 2026-03 的 US$250m，再於 2026-07 達 US$1bn，但 ARR 不等於已認列收入。來源：[[報告_Daiwa_中國基礎模型產業啟動覆蓋_20260811]]。

## 核心技術／競爭優勢

- **Coding 與 agent post-training**：公司稱在逾 10,000 個真實軟體工程環境做強化學習，以編譯、測試與工具執行作為較客觀的 reward signal；GLM-5 系列因此把 coding 作為切入長時程 agent 的主軸。
- **精實 active compute**：GLM-5.2 為 744bn 總參數、約 40bn active parameters。Daiwa 認為評估 serving economics 應看 active parameters 絕對量，不只看 activation ratio。
- **推理工程**：動態稀疏注意力、prefill／decode 分離、KV-cache 管理、speculative decoding、FlashComm、IndexShare 與 Slime asynchronous RL，目標是降低長上下文的每 token FLOPs 與 GPU 閒置。
- **本土晶片適配**：Lightning Indexer、通訊 kernel 與中介軟體調適，降低先進海外 GPU 受限時的部署風險；但 1GW 級規劃算力、50,000 顆本土加速器叢集的實際完工、利用率與經濟性尚未完整披露。
- **第三方分發**：GLM 可透過 Vertex AI、AWS Bedrock、OpenRouter、Vercel、Fireworks AI 與 Cerebras 取得，但第三方託管使用量未必轉為 Z.AI 收入。

## 供應鏈位置

- 上游：以租賃 NVIDIA 與本土 AI 加速器算力為主，並透過軟硬體協同降低國產晶片互連與 kernel 效率瓶頸；本批資料未揭露可驗證的特定供應商份額。
- 中游：GLM 模型、Open Platform／MaaS、coding 訂閱與企業 agent。
- 下游：第三方雲端／模型聚合平台、開發者、金融／國企及其他企業工作流。

## 風險與注意事項

> [!warning] 主要風險
> - 模型能力與 benchmark 領先變動快，API 標準化也使客戶切換成本偏低。
> - 雲端 API 2025 毛利率僅約 19%；Daiwa 的 2029 毛利修復與損平假設需價格、利用率與成本同時改善。
> - 先進 GPU 供給、租賃價格、本土晶片適配與美國 BIS Entity List 可能限制模型迭代及海外服務。
> - 大額融資降低短期流動性風險，卻無法替代 ARR 到收入、毛利與現金流的轉換。
> - 1GW 規劃算力與 50,000 顆本土加速器並非已驗證的在運產能。

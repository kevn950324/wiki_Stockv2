# MDB.US(mongodb)

## 基本資料

MongoDB（MDB.US）是全球領先的文件資料庫（Document Database）廠商，以 JSON 原生架構（BSON）區別於傳統關聯式資料庫。核心產品 **Atlas**（Cloud Database-as-a-Service）提供多雲部署、Vector Search、全文搜尋等功能，定位為「AI 時代的 Generational Data Platform」。

**FY 結束月份**：1 月（FY1Q27 = 2026 年 2-4 月）

---

## 核心技術／競爭優勢

- **JSON 原生架構**：非結構化資料處理能力優於關聯式資料庫，更適合 Agent 開發（動態 schema、Transactional Memory）
- **Atlas Vector Search / Voyage AI**：語意搜尋 + embedding 能力，Voyage AI Embeddings 已進入 Public Preview
- **單一平台整合**：Transactional Memory + Vector Retrieval + Embeddings 三合一，競爭 Agentic AI 資料層
- **MongoDB 8.3 效能**：讀取 +45%、寫入 +35%、Asset Transactions +15%
- **Enterprise Advanced（EA）**：支援公有雲 / 私有雲 / 地端（Hybrid）一致的資料平台，滿足大型企業混合架構需求
- **Frontier Lab 客戶**：已由單一客戶擴展至多家，承接 mission-critical AI 工作負載；Adobe Journey Agent 採用 MongoDB 作為長期記憶層

## AI 客群策略

管理層將 AI 機會分三大客群：

| 客群 | 現況 | 備註 |
|------|------|------|
| **Frontier Labs**（OpenAI、Anthropic 等）| 已由單一擴展至多家，承接 mission-critical workload | 資料量大、低延遲要求 |
| **AI Native 企業** | PostgreSQL 等架構規模化後出現效能瓶頸，轉向 MongoDB | JSON 原生架構優勢 |
| **大型企業 AI 部署** | 現有工作負載擴張為主，Agentic AI 仍處早期 | Atlas 遷移與 AI 導入同步進行 |

## 主要風險

> [!warning]
> - **成長動能集中**：Atlas 佔 75% 總營收，Atlas 成長放緩將直接衝擊整體
> - **Agentic AI 兌現時機**：大規模企業部署仍處早期，AI Native 增量貢獻尚小
> - **競爭**：PostgreSQL（開源）、Cassandra（大數據）、DynamoDB（AWS）、Cosmos DB（Azure）

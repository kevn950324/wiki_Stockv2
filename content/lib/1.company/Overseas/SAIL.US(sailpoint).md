# SAIL.US(sailpoint)

## 基本資料

SailPoint Technologies 是全球身份治理（Identity Governance and Administration, IGA）的市場領導者，總部位於美國德州奧斯汀，2005 年創辦，2022 年被 Thoma Bravo 私有化，2024 年重新上市（NYSE：SAIL）。公司專注企業身份生命週期管理（配給/撤銷），在大型企業（Global 2000）中有深度滲透，2026 年以「非人類身份（NHI）」與 Agentic AI 身份治理為核心成長驅動。

## 核心平台：Identity Security

| 產品 / 能力 | 說明 |
|---|---|
| Identity Lifecycle Management | 配給 / 撤銷 / 修改人類身份存取，是核心傳統業務 |
| Access Governance | 存取認證、違規偵測、SoD（職責分離）管控 |
| Machine Identity（NHI） | 管理 AI 代理人、服務帳戶、API 金鑰等非人類身份的存取與行為 |
| AI Governance Solutions | 動態監控、即時合規執法、AI 代理人政策管理 |

### Agentic AI 時代的定位

Truist（2026-06-08）將 SailPoint 定位為「Agentic AI 時代 Identity Security 的直接受惠者」：

- 企業平均每人超過 100 個機器身份，Agentic AI 進一步放大這個數字
- 代理人需要「配給 → 監控 → 撤銷」的完整生命週期治理——這是 SAIL 的核心能力
- SAIL 的 AI 治理解決方案標榜「動態管理、即時自適應、可執行政策」，與 ZS 的「流量審查」形成不同層次的競爭

## 投資觀察

### 多頭論點

1. **NHI 是結構性成長驅動**：機器身份爆炸式增長是長期趨勢，SAIL 是傳統 IGA 市場中最有資格延伸 NHI 治理的廠商
2. **Agentic Security Stack 中的身份層**：Truist 的 Agentic Security Stack 表格中，AI-IAM / NHI 類別的代表廠商為 PANW（CyberArk）、SailPoint、Okta、CrowdStrike——SAIL 是純身份治理的代表
3. **VAR 調查正面**（Jefferies 2026-04-16）：Agentic Identity Security 市場——16% VARs 選擇 SAIL 受益（與 OKTA 並列第三，落後 CYBR/PANW 44% 與 MSFT 32%）

### 主要風險

- 成長率波動大（CY26 45.5% vs CY27 18.2%），需觀察 FY26 基期效應後的可持續性
- 市值較小（$8.2B），對市場情緒敏感
- 競爭來自 OKTA（IGA 延伸）、PANW（CyberArk）、MSFT（Entra ID Governance）

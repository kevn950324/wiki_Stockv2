# 分析_中國基礎模型_Token經濟與算力瓶頸_20260905

## 問題背景

2026 年 8–9 月的七份產業／公司報告與一份 2023 年早期產業框架，同時指向一個核心問題：中國基礎模型的低價與 token 高增，能否轉成上市純模型公司的持久毛利與估值。這批資料的 thesis 是市場不必只剩一個模型贏家，但「能力溢價」與「成本效率流量」會形成不同商業路徑；真正共通的瓶頸是可用推理算力、每任務成本與 ARR 轉認列收入。

## 關鍵發現

- [[報告_Jefferies_中國AI_Token支出與模型效率_20260810]]（2026-08-10）記錄 OpenRouter 當週中國模型 token 約 34.2tn、週增約 22%，高於美國模型約 9.2tn；平台樣本顯示採用強，但不代表全市場收入。
- [[報告_Daiwa_中國基礎模型產業啟動覆蓋_20260811]]（2026-08-11）估中國 top-model median blended price 約 US$0.8／m tokens，對比美國約 US$6.6；價格差支持需求擴張，也意味毛利需靠效率與規模驗證。
- 同一報告指 [[2513.HK(z.ai)]] cloud ARR 於 2026-07 達 US$1bn，且 API 在提價後仍成長；能力較強的 coding／agent 模型存在定價空間，但 ARR 不等於收入。
- [[報告_Daiwa_MiniMax啟動覆蓋_20260811]]（2026-08-11）指 [[0100.HK(minimax)]] 9M25 海外收入占 73%，M3 以 428bn 總參數／22.5bn active parameters 主打低成本，全模態產品提供全球化與 B2C→B2B 飛輪。
- [[報告_JPM_GLM5.3與DeepSeek重新定價_20260816]]（2026-08-16）把競爭框架定義為能力與成本的 Pareto frontier；MoE、attention／KV-cache、量化、serving software 與 post-training 都會改變每任務成本。
- [[報告_UBS_中國AI與科技實地調研_20260814]]（2026-08-14）顯示中國算力生態同時推進 superpod、CPO、記憶體介面、封裝與電力，但多數仍是 prototype、規劃或產能時程，不能直接視為已量產收入。
- [[報告_Nomura_中國AI全球生成式AI發展映射_20230917]]（2023-09-17）早期即預期中國先由企業／政府 monetisation、消費端較慢；2026 年 API／MaaS 放量支持方向判斷，但盈利模式仍未完成驗證。

## 比較表

| 維度 | [[2513.HK(z.ai)]] | [[0100.HK(minimax)]] | 投資含義 |
|---|---|---|---|
| 主要定位 | coding／agent 能力與較高 API 定價 | 低成本、全模態與全球應用 | 前者偏能力溢價，後者偏使用量與應用廣度 |
| 2025 收入 | 約 RMB724m | 約 US$79m | 口徑不同，不直接比絕對規模 |

| 模型效率代理 | GLM-5.2：744bn total／40bn active | M3：428bn total／22.5bn active | MiniMax active compute 較小；Z.AI 以 post-training 與定價彌補 |
| 商業結構 | API／MaaS、企業 agent、私有部署 | AI-native B2C、Open Platform B2B | Z.AI 正從專案轉雲端；MiniMax 正從 B2C 轉 B2B mix |
| 全球化 | 218 國／地區分發，但第三方使用未必認列 | 9M25 海外收入占 73% | MiniMax 海外 monetisation 證據相對直接 |
| 2029 損平假設 | Daiwa 估 adjusted NPM 約 +1% | Daiwa 估 adjusted NPM 約 +10% | 都屬遠期高敏感 estimate |
| 主要風險 | 算力租賃、API 毛利、Entity List、解禁 | 模型競爭、算力、融資、著作權、解禁 | 風險溢價不能只用 EV/ARR 折價處理 |

## Insight 結論

| 結論 | 投資含義 | 信心 |
|---|---|---|
| 最重要的領先指標是「付費任務毛利」，不是 benchmark 或 token 份額 | 優先追蹤 API realized price、每任務 token、gross margin 與 cohort | 高 |
| 中國低價模型可能透過彈性需求放大總 token | 有利算力與服務量，但不保證模型商保留價值 | 中 |
| Z.AI 與 MiniMax 不是單純同質競爭 | 可用能力溢價 vs 成本／全模態兩條路徑比較 | 中 |
| 租算力降低 capex，不降低經濟成本 | compute service fee／revenue 比 capex ratio 更重要 | 高 |
| ARR 估值需大幅折價並做情境分析 | 私人同業倍數、gross／net 口徑與遠期損平均有偏差 | 高 |

> [!tip] 結論／投資觀點
> 中國基礎模型的投資主線不是「最強模型勝出」，而是誰能把能力與低成本同時轉成可認列、可續用且有正毛利的付費任務；短期看算力容量，中期看 API 毛利，長期看 workflow 黏著。
